# Security Policy

## Supported versions

Only the tags currently published on [Docker Hub](https://hub.docker.com/r/bigbossstudio/php) (`8.4-apache`, `8.5-apache`) receive security updates. They are rebuilt every Monday on top of the latest official `php` image.

## Reporting a vulnerability

If you discover a security vulnerability, please email **paris@big-boss-studio.com** instead of
using the public issue tracker.

- We aim to acknowledge your report within **5 business days**.
- Please do not publicly disclose the issue until a fix has been released.

We appreciate your help in keeping this image and its users safe.
